# ぽちっと反射神経 (Pochitto Reflex)

4つのテストで反応速度・判断力・集中力を測り、「反射神経年齢」を判定するカジュアルアプリ。
pochitto games / iOS (Capacitor 7) / 縦画面

- 本体: `www/index.html`（HTML/CSS/JSの1ファイル。外部素材なし、音はWeb Audio）
- ネイティブ連携: `www/native.js`（ATT → AdMob → 課金、振動、シェア、レビュー依頼）
- ビルド: `codemagic.yaml`（ぽちっと漢字と同じ構成）
- アイコン/スプラッシュ: `assets/`（ビルド時に `@capacitor/assets` で各サイズを生成）

## テスト
| モード | 内容 | スコア |
|---|---|---|
| 反応速度テスト | 赤→緑の瞬間にタップ ×5 | 平均ms（100ms未満は見込み押しでやり直し） |
| 押すな判定 | 緑「押せ」8問＋赤「押すな」4問 | 押せの平均ms＋ミス1回につき100ms |
| 色ことばテスト | ストループ。文字の色のボタンを押す ×20 | 正解の平均ms＋ミス1回につき300ms |
| 数字タッチ | 5×5の1〜25を順にタッチ | 秒（ミス1回につき+1秒） |

ランク（SS〜D）と上位％は、スマホのタッチ操作を前提にした目安の正規分布から計算する（`MODES` の mean/sd）。
反射神経年齢 = 20 + (平均ms − 250) / 2.5（8〜80歳に丸める。娯楽目的の目安）。

測定精度: 刺激を表示した直後の `requestAnimationFrame` の時刻を表示時刻、`pointerdown` の `event.timeStamp` をタップ時刻とする。

## 収益
- バナー: ホーム・結果・記録・設定の画面だけ（**測定中は出さない**）
- インタースティシャル: 5回目以降、測定3回ごとに、結果画面から次に進むとき
- 買い切り `pochittoreflex_remove_ads` ¥300
- レビュー依頼: 5回目以降で自己ベストを更新したとき（SKStoreReviewController）

## 開発
ブラウザで `www/index.html` を開けば、広告と課金なしでそのまま動く。
公開までの手順は `SETUP.md`、ストア掲載文は `STORE.md`。
